# 纳指 100 场外基金额度雷达

一套部署在 GitHub Actions 上的自动监控器：它每天检查国内公募的 **纳斯达克 100 场外 QDII 基金**，将最新公告中的申购、定投和限额信息整理为一张简洁的微信卡片，并通过 PushPlus 推送。

> 只跟踪场外基金及 ETF 联接基金；不跟踪纳斯达克股票，也自动排除直接在交易所买卖的场内 ETF。

## 你会收到什么

每条消息都包含：

- 正常开放、限额申购、暂停申购、待核验四种状态；
- 单日申购/定投限额（能可靠识别时显示金额）；
- 代销、直销或分渠道口径。支付宝属于代销渠道，但实际下单仍以支付宝页面为准；
- 与上一次结果相比的恢复开放、暂停、额度上调/下调等变化；
- 全量基金清单。相同产品中规则一致的 A/C、人民币/美元等份额会合并显示，避免消息冗长。

首次运行会建立基线并发送完整清单。之后每天首个成功任务发送日报；当天后续任务只有发现变化才会推送，避免重复打扰。

## 首次启用

1. 将本项目全部文件推送到仓库的默认分支。
2. 在仓库 **Settings → Actions → General** 中允许工作流拥有读写仓库内容的权限。工作流需要把最新快照提交回 `state/last_snapshot.json`，用于识别下一次变化。
3. 在 **Settings → Secrets and variables → Actions** 新增仓库 Secret：

   ```text
   PUSHPLUS_TOKEN
   ```

   填入你的 PushPlus 用户 Token 或消息 Token。Token 只由运行中的工作流读取，绝不写入代码、日志或提交记录。
4. 打开仓库的 **Actions**，选择“纳指100场外基金额度雷达”，点击 **Run workflow**。首次建议保持“立即发送一条完整日报”开启，用来确认微信能收到设计好的卡片。
5. 在 PushPlus 完成微信绑定和实名要求；未实名认证的账号无法调用微信发送接口。

## 自动运行时间

工作流在每个工作日的北京时间 **08:37、11:17、14:17** 运行。时间刻意避开整点与半点，以降低公共任务排队造成的延迟。

GitHub 的定时任务并不保证精确到分钟，因此本项目设置了多次检查，并采用“发现变化才额外提醒”的方式，而不是依赖单次准点执行。

## 数据口径与安全策略

- 基金池从公开基金代码表自动发现“纳斯达克 100 + QDII”产品；新产品通常无需手动增补。
- 状态以公告标题与正文为依据，并过滤境外节假日的短期暂停公告，避免把假期误报成长期限购。
- 当公告明确区分直销和代销渠道时，消息会明确标出“分渠道”，不会把直销额度错误当成支付宝额度。
- 公告正文无法可靠提取金额时，显示“待核验”，不会臆测数值。
- 若单次读取失败比例超过 25%，任务停止且不覆盖上一次可信快照，防止数据源波动引发误报。

这是一套公开信息提醒工具，不会下单、不会读取支付宝账户，也不构成投资建议。

## 调整范围

在 [config/settings.json](config/settings.json) 中维护范围：

- `exclude_codes`：排除不想跟踪的基金代码；
- `pinned_funds`：当自动发现暂未包含某只基金时，手动固定加入；
- `max_parallel_requests`：公告抓取并发数，默认 6，已经兼顾速度和数据源压力；
- `max_failure_ratio`：单次最大容错比例，默认 25%。

不要把 PushPlus Token 写进这个文件。

## 本地校验

项目只使用 Python 标准库，不需要安装任何依赖。

```bash
python -m unittest discover -s tests -v
python src/main.py --dry-run --force-digest
python src/main.py --preview
```

`--dry-run` 会读取真实公开数据、生成消息卡片，但绝不发送；`--preview` 不联网，只用最近一次快照重建卡片，适合检查排版。

## 目录说明

```text
.github/workflows/quota-radar.yml   GitHub 自动任务
config/settings.json                监控范围、数据源与安全阈值
src/main.py                         采集、解析、比对、排版与推送
state/last_snapshot.json            上一次可信状态（由 Actions 自动维护）
tests/test_main.py                  解析、范围和排版的基础测试
```
